# hotaru - 思考を冷やす夜の灯

## 1. プロジェクト概要
**hotaru（ホタル）** は、現代社会の過度な成長・変化・評価の波に晒され、脳が「ストレス思考」に晒されている人々へ、思考を冷却し、感情を放熱するための「静かな夜の避難所」をデジタルプロダクトとして提供するプロジェクトです。

### 設計思想：Calm UX (穏やかなUX)
- **継続を強要しない**: ストリーク機能やプッシュ通知による再訪促進を排除。
- **評価しない**: AIはユーザーの感情を分析・評価・診断せず、ただ隣にいる「hotaru」として振る舞う。
- **通過点であること**: 依存させるのではなく、嵐の夜を過ごし、次の場所へ向かうための停留所を目指す。

---

## 2. システム構成・アーキテクチャ

### 全体像
LINE公式アカウントを入り口とし、LIFF（LINE Front-end Framework）を介して提供されるWebアプリケーション（PWA対応）です。

### 技術スタック
- **Frontend**: HTML5 / CSS3 (Vanilla CSS) / JavaScript (Vanilla JS)
  - **PWA**: ホーム画面への追加により、LINEの喧騒（通知バッジ等）を介さず直接アクセス可能。
- **Backend**: Node.js (Vercel API Routes 想定)
  - **AI Engine**: Google Gemini API
    - `gemini-3.5-flash`: 通常の対話用（高速・低コスト）
    - `gemini-3.1-pro`: 「レポート」生成用（高度な文脈理解）
- **Platform/External**:
  - **LINE**: Messaging API / LIFF
  - **Payment**: Stripe（サブスクリプション・お裾分け課金）
  - **Analytics**: Google Analytics 4 (GA4) による行動ログ計測（属性特定は行わない）

## 3. 主要な機能の技術的背景

### ① 思考の冷却（なごりを残す・消す）
- 名古屋大学の研究に基づく「10秒呼吸法」を視覚的にガイドするUI。または1/fゆらぎの視覚化。
- 画面の明度や背景音を段階的に減衰させる「鎮静」の演出。

### ② 低負荷AI対話
- サーバーサイド（`api/chat_v2.js`）で厳格な **System Instruction** を管理。
- 解決策を提示せず、短文で余韻を残す応答に特化。
- 希死念慮などのリスクワード検知時には、専門窓口への案内を優先表示。
- どの画面においても緊急用プロトコルを設置。
- ユーザーの入力に対して、AIが即座に反応するのではなく、少し間を置いてから反応することで、ユーザーに考える時間を与える。


### ③ あさやけ（14日間レポート）
- 有料ユーザー向けに、過去14回分の「滞在時の空気感」を可視化。ネガティブだけでなく、ポジティブなワードや「なごり」の要素も可視化する。
- 会話の具体的な文脈を保存し続けるのではなく、空気感や変化をAIが要約してフィードバック。

## 4. 運用・保守方針

本プロジェクトは、代表（PO）が自ら微調整を行える「自走可能性」と、深い技術領域を専門家に委ねる「安全性・低負荷」の両立を目指しています。

### 自身で対応可能な範囲
- AIプロンプト（System Instruction）の改善・微調整
- UIの文言・ラベルの変更
- 14回分のレポートの出力ロジックの調整
- Google Analyticsによる利用状況のモニタリング

### 専門家（外注）へ依頼する範囲
- インフラ（サーバー・DB）の深いトラブル対応
- LINE APIやStripe等の外部API大幅アップデート対応
- セキュリティ脆弱性への対応
- 大規模な新機能追加・UI刷新
